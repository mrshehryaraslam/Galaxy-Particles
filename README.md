# Galaxy Particles

An interactive 3D galaxy particle animation built with **Three.js**, **GSAP**, and **Vanilla JavaScript**. Users can type custom text and watch the particle system morph into animated shapes with smooth motion and pointer interaction.

## Features

- Interactive 3D particle galaxy
- Text-to-particle morph animation
- Smooth GSAP transitions
- Mouse and touch interaction
- Responsive full-screen layout
- Clean UI with modern glass-style input
- Lightweight static frontend project

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Run `index.html` in your browser.

For best results, use a local server:

```bash
# VS Code Live Server extension recommended
# or use Python
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```
